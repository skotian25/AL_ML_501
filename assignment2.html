The Big Picture

A neural network learns patterns by adjusting numbers, step by step, to reduce its mistakes.

A neural network is a stack of simple calculating units called neurons, arranged in layers. Data goes in, passes through the layers, and a prediction comes out. Training compares predictions with correct answers and adjusts the network’s internal numbers.

Layers and Neurons

The building blocks of the architecture

Layers

What it is

A group of neurons at the same depth in a network. Networks have input and output layers and may have one or more hidden layers.

Role

Inputs receive features, hidden layers transform them, and the output layer makes the final prediction. More layers can learn more abstract patterns.

In the Playground

Use + and − to add or remove hidden layers.

Neurons

What it is

A small computing unit: multiply inputs by weights, add a bias, and apply an activation function.

Role

Each neuron detects a small pattern; its output becomes an input to the next layer.

In the Playground

Each square is a neuron. Hover to inspect the pattern it has learned.

Neural Network Components04 / 10

Weights

The learned strength of every connection

What it is

A number attached to a connection between neurons. A large positive weight increases influence; a negative weight decreases it; a weight near zero means the input has little influence.

Role

Training repeatedly adjusts weights so predictions better match correct answers. A bias is another learned parameter that shifts a neuron's response.

In the Playground

Thicker lines mean stronger connections. Blue indicates positive weights; orange indicates negative weights.

Activation Functions

Decide whether, and how strongly, a neuron passes its signal on

ReLU

max(0, x)

Output: 0 and up

Passes positives, blocks negatives. Common in hidden layers.

Tanh

tanh(x)

Output: −1 to 1

A smooth S-curve centered on zero.

Sigmoid

1/(1+e⁻ˣ)

Output: 0 to 1

An S-curve useful for probability-like outputs.

Linear

f(x) = x

Output: any value

No nonlinearity; stacked linear layers remain linear.

Why it matters: Without nonlinear activations, stacking layers still gives a linear model. Nonlinearity enables curved and complex decision boundaries.

Loss Functions and Optimization Algorithms

How the network measures its error and how it improves

Loss function

What it is

A formula that turns the difference between predictions and correct answers into a number. Examples: mean squared error and cross-entropy.

Role

Measures how wrong predictions are. Training aims to reduce this value.

In the Playground

Training loss and test loss appear at the top right.

Optimization algorithm

What it is

A method for updating weights to reduce loss. Gradient descent uses gradients computed through backpropagation.

Role

Moves weights in a direction that lowers loss. The learning rate controls step size.

In the Playground

Adjust the learning rate and regularization (L1 or L2).

How the Pieces Work Together

Training is a repeating cycle of predict, measure, and adjust

1Forward pass

Inputs pass through layers, weights, and activations to make a prediction.

2Compute loss

Compare the prediction with the correct answer.

3Backpropagation

Compute how much each weight contributes to the loss.

4Update weights

The optimizer adjusts weights to reduce loss.

Repeat: Train for many rounds (epochs) until the loss stops improving. TensorFlow Playground visualizes the process.

Summary

Why visualizing neural networks matters

It opens the black box

Seeing weights, layers, and decision boundaries makes abstract models easier to inspect.

Nonlinearity is essential

Activation functions enable networks to learn curves instead of only straight-line relationships.

It builds intuition

Changing size, noise, and learning rate reveals important trade-offs.

Training is a cycle

Predict, measure the loss, and adjust weights repeatedly.

It speeds up debugging

Comparing training and test loss can help identify overfitting.

Bigger is not always better

Useful features and clean data can matter as much as additional layers or neurons.
