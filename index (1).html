The ten algorithms

Filter by learning type or application domain.

01

Linear & Logistic Regression

Supervised
Tabular Data

How it works

Fits a straight line (or an S-shaped curve for logistic regression) between the input features and an outcome by finding the weights that minimize prediction error.

Real-world use cases

  • Predicting house prices
  • Flagging customers likely to cancel a subscription
02

Decision Tree

Supervised
Tabular Data

How it works

Asks a sequence of yes/no questions about the features, each chosen to split the data into purer groups, until every leaf gives a prediction.

Real-world use cases

  • Loan approval decisions
  • Sorting fruit by weight, size, and color
03

Random Forest

Supervised
Tabular Data

How it works

Trains many decision trees on random samples of the data and features, then combines their votes so individual errors cancel out.

Real-world use cases

  • Credit card fraud detection
  • Predicting equipment failure
04

Gradient Boosting (XGBoost)

Supervised
Tabular Data

How it works

Builds trees one after another, with each new tree trained to correct the mistakes of the trees before it.

Real-world use cases

  • Credit scoring
  • Retail demand forecasting
05

Support Vector Machine

Supervised
Tabular DataNLP

How it works

Finds the boundary that separates classes with the widest possible margin. Kernel functions let it draw curved boundaries for harder problems.

Real-world use cases

  • Spam email filtering
  • Categorizing support tickets by topic
06

K-Means Clustering

Unsupervised
Tabular Data

How it works

Picks k cluster centers, assigns each data point to its nearest center, then moves each center to the average of its points. It repeats until the groups stop changing.

Real-world use cases

  • Customer segmentation for marketing
  • Grouping similar products
07

Principal Component Analysis (PCA)

Unsupervised
Tabular DataComputer Vision

How it works

Finds new axes that capture the most variation in the data, so many features can be reduced to a few with little information lost.

Real-world use cases

  • Compressing sensor data
  • Visualizing high-dimensional data and compressing face images
08

Convolutional Neural Network (CNN)

Supervised
Computer Vision

How it works

Slides small learned filters across an image to detect edges, then textures, then shapes. Stacked layers build up from simple patterns to full object recognition.

Real-world use cases

  • Detecting defects on a production line
  • Reading medical scans
09

Transformer (Large Language Model)

Hybrid
NLPGenerative AI

How it works

Uses attention to weigh how every word relates to every other word. It is pretrained without labels to predict the next word, then fine-tuned with labeled examples for specific tasks.

Real-world use cases

  • Chatbots and virtual assistants
  • Translation, summarization, and code generation
10

Diffusion Model

Unsupervised
Computer VisionGenerative AI

How it works

Learns to remove noise from images step by step. To create something new, it starts from pure noise and repeatedly denoises it into a finished image.

Real-world use cases

  • Text-to-image generation
  • Creating synthetic training data and restoring damaged photos

Key takeaways

Match the method to the dataSpreadsheet-style data favors trees and regression. Images favor CNNs. Language and generation favor Transformers and diffusion models.
Labels decide the learning typeIf you have known answers, use supervised learning. If you only want to discover groups or compress data, use unsupervised learning.
Simple often winsInterpretable models like regression and decision trees remain the right choice when explaining a decision matters as much as accuracy.
Ensembles build on treesRandom Forest and Gradient Boosting combine many Decision Trees, trading some interpretability for much higher accuracy.
